# TELC B1 Günlük Almanca Çalışma

Ücretsiz, giriş gerektirmeyen TELC B1 hazırlık sitesi.

## İçerik

- Günün motivasyonu
- Günün 10 kelimesi
- Kelime quizi
- Grammar testi
- Grammar konu anlatımları
- Günlük 200 kelimelik sözlük
- TELC B1 günlük görevleri
- PWA/offline temel destek

## Yayınlama

Bu proje statik HTML/CSS/JS ile çalışır. GitHub Pages, Netlify veya Vercel üzerinde build komutu gerekmeden yayınlanabilir.

## GitHub Pages ile Online Yapma

1. GitHub'da yeni bir repository oluştur.
2. Bu klasördeki dosyaları repository'ye yükle.
3. Repository içinde `Settings` -> `Pages` bölümüne gir.
4. Source olarak `Deploy from a branch` seç.
5. Branch olarak `main`, folder olarak `/root` seç.
6. Kaydet. Birkaç dakika sonra site şu formatta açılır:

`https://kullanici-adin.github.io/repo-adi/`

## Google'da Çıkması İçin

- Önce site GitHub Pages, Netlify, Vercel veya özel domain ile online olmalı.
- Google Search Console'a site URL'sini ekle.
- URL Inspection bölümünden ana sayfayı dizine ekleme isteği gönder.
- Site birkaç gün içinde Google sonuçlarında görünmeye başlayabilir.

Sadece tarayıcı adres çubuğuna site adını yazınca açılması için özel domain gerekir. Örneğin `telcb1almanca.com` gibi bir domain alınıp hosting'e bağlanabilir.
